# Implementation Plan

## Overview

This plan implements S3 + CloudFront infrastructure for hosting product images, starting with a single test image generated by Nova Canvas. The implementation validates CORS and CSP configuration before expanding to all products.

## Tasks

- [x] 1. Add S3 and CloudFront to CDK stack
  - Create S3 bucket "chatgpt-apps-aws" with private access
  - Configure CORS on S3 bucket (allow GET from any origin)
  - Create CloudFront Origin Access Identity (OAI)
  - Create CloudFront distribution with S3 origin
  - Configure CloudFront: HTTPS-only, compression, HTTP/2
  - Add CORS response headers to CloudFront
  - Output CloudFront domain name
  - _Requirements: 1.1, 1.2, 1.3, 1.4_

- [x] 2. Update Lambda environment with CloudFront domain
  - Add CLOUDFRONT_DOMAIN environment variable to Lambda function
  - Set value from CloudFront distribution domain output
  - _Requirements: 2.3_

- [x] 3. Add CSP configuration to MCP tools
  - Update search_products tool to include openai/widgetCSP metadata
  - Add CloudFront domain to resource_domains list
  - Use CLOUDFRONT_DOMAIN environment variable
  - Update get_product_details tool with same CSP configuration
  - _Requirements: 2.1, 2.2_

- [x] 4. Create image upload script
  - Create scripts/upload_to_s3.py
  - Implement function to upload image bytes to S3
  - Set Content-Type: image/png
  - Set Cache-Control: public, max-age=86400, immutable
  - Generate S3 key: images/{product_id}.png
  - Return CloudFront URL: https://{domain}/images/{product_id}.png
  - _Requirements: 3.2, 3.3_

- [x] 5. Create test script for single image
  - Create scripts/test_single_image.py
  - Read first product from data/products.json
  - Generate image using Nova Canvas (reuse existing code)
  - Upload generated image to S3
  - Print CloudFront URL for manual testing
  - _Requirements: 3.1, 3.2, 3.3_

- [x] 6. Deploy and test infrastructure
  - Deploy CDK stack
  - Wait for CloudFront distribution to deploy (~15-20 minutes)
  - Run test_single_image.py script
  - Test CloudFront URL with curl (verify HTTP 200 and CORS headers)
  - _Requirements: 4.1, 4.2_

- [ ]* 7. Manual verification in ChatGPT
  - Manually update first product in data/products.json with CloudFront URL
  - Run python3 scripts/load_catalog.py to index to OpenSearch
  - Test in ChatGPT: search for first product
  - Verify image loads without CORS errors
  - Verify no CSP violations in browser console
  - _Requirements: 4.3_

- [ ]* 8. Document CloudFront domain and next steps
  - Add CloudFront domain to README or deployment notes
  - Document manual steps for updating products.json
  - Document how to expand to all products (future work)
  - _Requirements: 1.4_

## Notes

- **CloudFront Deployment Time**: 15-20 minutes for distribution to become available
- **Manual Steps**: products.json update and load_catalog.py run are manual for this test
- **Optional Tasks**: Tasks 7-8 are marked optional (*) for faster MVP - can be done manually
- **Core MVP**: Tasks 1-6 provide working infrastructure and test image upload
- **Future Work**: After validation, create bulk upload script for all products
- **Rollback**: Can revert products.json and redeploy if issues occur

## Testing Checklist

After completing all tasks:

- [ ] CloudFront URL returns HTTP 200
- [ ] CORS headers present in response
- [ ] Image displays in ChatGPT web component
- [ ] No CORS errors in browser console
- [ ] No CSP violations in browser console
- [ ] Image loads from CloudFront (check Network tab)
